# Feature Engineering Journey 🚀

This repository contains my learning and practice work in Feature Engineering for Machine Learning.

## 📚 Topics Covered So Far

### 1. Types of Missing Values

* Missing Completely At Random (MCAR)
* Missing At Random (MAR)
* Missing Not At Random (MNAR)

### 2. Missing Value Handling

* Identifying Missing Values
* Mean Imputation
* Median Imputation
* Mode Imputation
* Random Sample Imputation

### 3. Handling Imbalanced Datasets

* Random Oversampling (Upsampling)
* Random Undersampling (Downsampling)
* Introduction to SMOTE (synthetic minority over    sampling technique)

### 3. Handling Outlier using Python
* Minimum value
* Q1 25% (quartile)
* Median
* Q3 75% (quartile)
* IQR (Inter Quartile Range)
* lower bound = Q1 - 1.5 * IQR
* upper bound = Q3 + 1.5 * IQR
* show the outlier using box plot
